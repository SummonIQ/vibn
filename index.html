How It Works

From prompt to committed code

01

Type a task

Plain English. Describe what you want — add a feature, fix a bug, refactor a module, write tests.

02

Agent works autonomously

Reads your codebase, searches for context, writes and edits files, runs commands. Up to 30 tool calls per request.

03

Review every change

Each file write shows a unified diff. Press y to apply, n to skip. Nothing lands without your approval.

04

Ship it

/commit generates a commit message from your diff. Review, confirm, done.

Features

Built for real work

Not a chat wrapper. A proper agent loop with tool calling, inline diff review, project memory, and a keyboard-driven interface.

Full-Screen TUI

Rich terminal interface with split-pane output, streaming responses, scroll history, and a processing animation. Built on Ratatui and Crossterm.

Agent Tool Loop

Up to 30 rounds of autonomous tool calling per request. The agent reads code, makes edits, runs tests, and iterates until the task is done.

Inline Diff Review

Every file write shows a unified diff before it lands. Press y to apply or n to skip — no changes happen without your say-so.

/test Loop

Set a test command with /test bun run test. The agent runs it, reads failures, fixes the code, and re-runs until green. Up to 5 auto-fix iterations.

Agent Memory

Tell the agent things once with /remember and it knows them forever — scoped per project. /memory lists facts, /forget removes them.

Destructive Command Guard

Detects dangerous operations like rm -rf, git push --force, and DROP TABLE. Prompts for confirmation before executing.

Smart Autocomplete

Tab-completable / commands sorted by usage frequency. Auto-runs no-arg commands on Enter. File path completion for shell commands and /cd.

AI Commit Messages

/commit feeds your staged diff to the agent, proposes a commit message, and lets you confirm, cancel, or open your editor to tweak it before committing.

Project .vibn Config

Drop a .vibn file in any project to preset the model, system prompt, constraints, and test command. Auto-loaded on startup and after /cd.

Constraints

Rules the agent always follows

Define project-wide rules in plain English. The agent reads them before every response. Manage them with a keyboard-driven TUI — no config files to edit manually.

Constraints TUI

Open /constraints to see your rules list. Arrow keys to navigate, a to add, e to edit, d to delete, q to save and quit.

Persistent Rules

Constraints are saved to ~/.vibn/constraints.json and injected into every system prompt automatically — no need to repeat yourself.

Stack-Specific Guidance

Examples: "Always use Tailwind, never inline styles." "Use the existing Modal component." "Never use npm — use bun."

Interface

A terminal UI that gets out of the way

Keyboard-first design. Vim-style navigation in menus. No mouse required.

Slash Commands

/cd /tree /git /model /status /compact /reset /remember /commit /test /compare /watch /prompts /search /find /constraints /sessions /help

Interactive Menus

Arrow keys or j/k to navigate. Enter to select. / to search. q or Esc to go back. PgUp/PgDn for pages. Works in marketplace, skills, MCP manager, and model picker.

Tab Completion

Type / and press Tab to cycle through commands sorted by frequency. Works for file paths after ! and /cd too. Shift+Tab goes backward.

Scroll & History

Scroll through output with Ctrl+Up/Down. Command history persisted across sessions. Ctrl+R for incremental history search.

Named Sessions

Start with ./vibn --session myproject to resume a prior conversation exactly where you left off. /sessions lists all past sessions with timestamps.

Conversation Management

/compact compresses old messages into a summary to save context window. /reset clears everything for a fresh start.

Rich Rendering

Markdown, syntax highlighting, and structured panels for tool results. Errors highlighted in red. Tool calls shown in cyan.

Get Started

Three commands. That's it.

terminal
# 1. Install Ollama
$ brew install ollama && ollama serve

# 2. Pull a model
$ ollama pull qwen2.5-coder:7b
# Optional upgrade: ollama pull qwen2.5-coder:14b

# 3. Clone and run
$ git clone https://github.com/yourusername/vibn && cd vibn
$ cargo build -p vibn
$ ./vibn

Vibn ready. Model: qwen2.5-coder:7b · /help for commands

MCP support is built into the Rust runtime.

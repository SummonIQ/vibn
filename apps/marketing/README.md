# vibn-marketing

Marketing site for [Vibn](https://vibn.dev) — a local AI coding agent.

Next.js 16 · React 19 · Tailwind v4 · Framer Motion · Bun.

## Develop

```bash
bun install
bun dev
```

Open http://localhost:30100.

## Deploy

Auto-deploys to Vercel on push to `main`. Production: https://vibn.dev.
